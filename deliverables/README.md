- 核心文献共3项研究：2025年修订工作论文、上传的中文期刊论文，以及期刊官网公开的替代论文。旧稿及未取得全文的文献单独留档。

- 五题来源和证据页码已整理；完整公告原页归档及B/D独立复核仍未完成。
- 8家公司及模型配置是建议，需在预实验后冻结。API预算100元；价格与版本按实际调用时点再次确认。
- 赛事截止、格式等要求仍待原通知核实。BCD通知中的日期是本轮建议安排。

```sh
sha256sum -c SHA256SUMS.txt
```
