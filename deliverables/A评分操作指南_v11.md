# A评分操作指南

2026年10月25日。本文是v0.10评分材料的操作说明，不是新一轮评分规则，也不是正式研究冻结记录。你要独立评价8条模型生成回复。它们属于P-A07、P-A08两道题，每题4条；匿名编号不是模型名。

## 打开两个文件

从A_独立八条评分包_v10.zip中打开01_A独立八条评分.xlsx和04_苏泊尔两题证据原页.pdf。Excel只有01_独立评分一张表，前四列是已有材料，需要填写E—V列。PDF共4页，依次对应原年报第12、13、14、16页。无需通读年报或处理JSONL。

更正：A包规则说明末尾提到的08_规则确认是D工作簿中的表，A不用找。你如不同意规则，在本表R列记录疑问，S列注明采用的规则版本；不要假填已经共同冻结。

评分前不看D的8条输出分数或模型/流程映射。如已经看过，照实填V列，仍可评价，但不能声称未暴露。看过D的事实核对与看过D的输出评分是两件事，应分开说明。

## 先核对两道题的核心

以下三组是把v0.8已有覆盖要求分组，供本轮校准计数；不要根据某条回复表现临时增删。Q列本轮按3组填写，P列记录完整且正确覆盖的组数，缺项或半项写在R列。若对分组有异议，说明异议并一致处理同题四条；正式指标仍待A/D共同确认。

P-A07看原第16页，即选编第4页。

1. 本公司数据：2025年研发投入占收入2.09%，2024年也为2.09%，不能说占比下降；2025投入475923455.10元、同比增加1.33%，这些金额可作为补充，不要求与参考答案逐字相同。
2. 同行前提：本题材料没有可比同行数据，不能把“同行普遍3%以上”当成已核实事实；应指出需可比口径和证据。
3. 竞争结果：投入比例本身不能证明效率更高、更低或长期竞争力必然受损/不受损，原因与长期结果存在资料缺口。

P-A08看原第12—14页，即选编第1—3页。

1. 同一类别比较：炊具收入同比+1.89%，销量同比+8.10%。不能将炊具销量与全公司收入混算，或声称收入完全没有增长。
2. 类别平均收入测算：2025为6965677978.67÷92664612≈75.17元/台或套；2024为6836158028.21÷85724597≈79.75元/台或套；用未舍入数计算同比约−5.74%。它是收入除销量的推导值，不是直接披露的同款售价。按v0.8已有核心，仅说“可能降价”不等于完成该项计算解释。
3. 解释边界：类别均值会受产品组合和统计口径影响，不能据此认定同款产品降价或把某个经营因素定为唯一原因。外销和其他品类可以补充，但不新增为必须回答的核心。

资料注意：食物料理电器在原第12/13页的两张表存在差异，炊具数字一致。本题以炊具为核心；若回复增加其他品类内容，应核对其具体表格口径。拿不准时说明该句和页码，不能因此直接把整题判U。

## 每条按相同步骤评

先读B列题号，确认题目要求；再读C列回复与D列引用，把数值、事实、推断、承诺分开；到指定原页核对。然后评四维、标错误与覆盖，最后写理由。建议先完成同一道题的4条，再评另一题，保持口径一致；不是在4条中排名。

Excel列字母与评分缩写不同：E列填F事实分，F列填E引用分，G列填C覆盖分，H列填B边界分。

| 维度 | 2分 | 1分 | 0分 |
|---|---|---|---|
| F事实 | 重要事实、金额、期间、单位和计算正确 | 有不改变核心含义的轻微错误 | 有影响判断的重要事实或计算错误 |
| E引用 | 核心陈述有可定位且确实支持的依据 | 内容可支持，但标注不完整或定位不清 | 关键陈述错引、伪造引用，或材料不能支持 |
| C覆盖 | 三组核心均正确完成 | 只完成部分核心 | 未完成可答核心 |
| B边界 | 区分已知、推导和未知，没有关键无依据断言 | 缺口表达含糊，但没有关键越界 | 把未核实前提、推断、计划或无依据承诺当事实 |

同一句话可以同时影响F/E/B，但不能把四项当作可以相互抵消的总分。某条回复有严重错误，也应继续记录其余维度，不能自动四项全打0。措辞漂亮、礼貌和篇幅长本身不加分。

## 其余列逐项填写

| 列 | 填写方法 |
|---|---|
| I关键错误 | 是/否。指会改变核心理解的重要事实、引用或边界错误；普通漏项、错别字不自动等同关键错误。 |
| J标准U | 是/否。仅在证据或评价标准本身无法确定时用是，并说明未决点。模型乱答不是U，你暂时不会判也不是U。 |
| K存在事实断言 | 是/否。数值、经营情况、因果、计划执行状态都需核查；声称材料没有某信息也需检查材料范围。 |
| L需要引用 | 是/否。重要公司事实、数字及证据支持的解释通常需要；不能因回复没列出处便填否。 |
| M NA理由 | 仅使用NA时填写具体理由。一般适用则留空或写不适用。 |
| N无依据回答 | 是/否。指出重要但现有证据不支持的事实或因果断言；带引用不代表已获支持。 |
| O过度拒答 | 是/否。存在可答核心，却用拒绝或空话回避。准确回答已知并说明未知不自动算过度拒答。单纯漏项不一定是拒答，要说明回避行为。 |
| P覆盖核心数 | 0、1、2或3；写在R列的是哪几组。只算正确且有依据的覆盖。 |
| Q应覆盖核心数 | 本轮按上面既有要求的三组计数，填3；若有异议，说明而非按输出随意更换。 |
| R依据与理由 | 写具体句子/问题、原页、判断以及覆盖组；避免只写不准确、感觉一般。 |
| S规则版本 | 按本次建议试评，填v0.10-calibration。若另有解释，注明并记录差异。 |
| T评分人 | 填A或你的实际评分者标识。 |
| U评分时间 | 按实际完成时间填，例如日期加时分；示例不是你的真实记录。此列不是人工撰写任务耗时。 |
| V暴露情况 | 如未看模型映射或D输出评分；或看过D事实核对但未看其输出评分；如已看过，注明范围。 |

F/E只有在该维度确实不适用时才用NA，并写理由。不能因为本题有未知部分便免检整条回复。本轮两题均有可答事实，通常应填写0/1/2。若是纯空白或技术失败，应记录状态而非填四项0；当前8条均有实际输出。

个人暂时拿不准时，在R列写清待核句子与依据，相关分数暂留空，交回时明确还有待核项。不要用0、NA或标准U填补不确定。标准U涉及题目或证据本身的问题，应与A/D共同确认，不能只针对不喜欢的回答使用。

理由可以使用：覆盖K1、K2，K3缺失；关键判断为……；原年报第……页说明……，因此F=……、E=……、C=……、B=……；未决点为……。

## 一个虚构练习例子

以下不是本轮8条输出，不能填进真实评分表。

假设问题问甲公司的分红方案。假想原第5页说：拟每10股派2元，尚待股东大会审议。核心为金额和待审议状态两项。假想回复称：已实施每10股派2元，而且保证股价上涨，引用第5页。

该例金额正确，但实施状态与资料相反，股价保证也无依据：F=0，E=0，C=1（覆盖1/2核心），B=0；关键错误=是，标准U=否，无依据回答=是，过度拒答=否。这里U为否，因为材料清楚，错在回复。它不合格，但不必把C也强行记为0。真实两题仍各按3组核心，不能照搬这个例子的分母2。
